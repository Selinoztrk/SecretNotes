# SecretNotes

A simple Python application that allows users to securely save and view notes using a master password. The program features basic encryption for note content and provides a terminal-based interface.

---

## Features

- Set a master password to access notes.
- Save, view, and manage secret notes.
- Note encryption using basic methods.
- User-friendly command-line prompts.

---

## Technologies Used

- Python 3
- `tkinter` for GUI
- `base64` (if used, optional—verify based on your implementation)

---

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Selinoztrk/SecretNotes.git
   cd SecretNotes
   ```
2. Install any required libraries:
   ```bash
   pip install base64 # if needed
   ```
3. Run the script:
   ```bash
   python main.py
   ```
4. Use the interface to enter your master password and start saving/viewing notes.
